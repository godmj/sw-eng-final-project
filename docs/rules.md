# 전투 규칙 명세 (v0.1, 2026-11-25)

정찬호님 제안(11/25)과 신민지 결정을 합친 규칙입니다. 수치는 테스트하면서 밸런스를 조정하고, 바뀌면 이 문서와 CHANGELOG를 갱신합니다.

## 1. 공통 규칙
| 항목 | 규칙 |
|---|---|
| 명중 | 기본 90% + 게임이 넘기는 보정값(실명 등). 보정은 퍼센트 정수 |
| 치명타 | 피해 2배. 확률은 직업별(아래 표) |
| 기본 공격 피해 | 공격력 그대로 |
| 방어 행동 | 받는 피해 x0.5. 다음 자기 턴 시작에 해제 |
| 쿨다운 | MP 없이 쿨다운만 사용. 자기 턴 시작(onTurnStart)에 1 감소 |
| 파티 | 전사, 궁수, 사제 3인 파티로 확정 |
| 스테이지 사이 | 아군 HP 회복 없음(유지) |
| 적 행동 | 방어하지 않음. 기본 공격과 스킬만 사용 |
| 턴 순서 | priority 내림차순 → speed 내림차순 → 파티 순서(전투 시작 때 한 번 정렬) |
| 라운드 상한 | 30라운드. 도달 시 양 팀 HP 합 비율로 승패, 같으면 무승부 |

## 2. 피해 계산 순서 (받는 쪽 기준)
1. 무기막기 중이면 피해 0 (1회 소모)
2. 방어 버프 x0.7
3. 방어 행동 x0.5
4. 갑옷 -5 (전사만)
5. 최소 1 (단, 1번에서 막힌 경우는 0)

독·화상 같은 지속 피해는 방어를 무시하는 피해(takeTrueDamage)로 적용한다.

## 5. 상태이상
| 이름 | 효과 | 지속 | 보관 |
|---|---|---|---|
| 화상 | 턴당 5, 방어 무시 | 3턴 | 게임(엔진) |
| 독 | 턴당 3, 방어 무시 | 4턴 | 게임(엔진) |
| 실명 | 명중 -30% | 2턴 | 게임(엔진) |
| 공격 버프 | 공격력 +30% | 3턴 | 캐릭터 |
| 방어 버프 | 받는 피해 x0.7 | 3턴 | 캐릭터 |
| 무기막기 | 다음 공격 1회 무효 | 다음 자기 턴 시작까지 | 캐릭터 |

- 같은 이름이 다시 걸리면 중첩하지 않고 지속시간만 갱신한다.
- 속도를 바꾸는 효과는 두지 않는다(턴 순서 재정렬 방지). 어지러움은 제외.
- 버프·막기는 attack()/takeDamage() 안에서 계산되므로 캐릭터가 보관하고, 독·화상·실명은 게임이 보관한다.

## 6. 인터페이스 영향
- 사제 힐을 위해 `Combatant`에 `int heal(int amount)`(실제 회복량 반환)를 추가한다. (신민지 동의, 구현 예정)
- 스킬 전용 ActionResult 생성이 필요하면 api/ 합의 후 추가한다. 현재 useSkill은 `ActionResult.attack(...)`으로 임시 처리.
- 연사처럼 한 행동에서 여러 번 명중 판정이 나는 경우, 결과에 명중 횟수를 담을지 논의 필요(임시로 합산 피해 1건으로 반환).
- 적 AI: 스킬을 쓸 수 있으면 스킬, 아니면 기본 공격(구현 예정).

## 7. 시뮬레이션 참고 (대략 계산, 2026-11-25)
단순 가정(적은 첫 번째 아군을 공격, 아군은 스킬을 순서대로 사용)으로 2,000회 돌린 결과.
- 전사 1명: 스테이지 사이 회복 0%·50%·100% 모두 클리어 0%, 대부분 드래곤에서 패배
- 3인 파티: 회복이 없어도 클리어 100% (오히려 쉬울 수 있어 난이도는 테스트하며 조정)
