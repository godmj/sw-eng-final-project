# 소프트웨어공학 기말 프로젝트 — Java 턴제 RPG

플레이어 파티가 3개 스테이지의 적을 쓰러뜨리고 마지막에 왕(드래곤)을 처치하는 콘솔 게임입니다. (카테고리 1)

## 팀
| 이름 | 담당 | 폴더 |
|---|---|---|
| 신민지 (godmj) | 게임 흐름, 턴 순서, 입출력, 상태이상 진행, 공통 인터페이스 | `api/`, `game/` |
| 정찬호 (chanho240384) | 캐릭터(전사, 드래곤), 전투 규칙, 스킬, 상태이상 내용 | `characters/` |

## 폴더 구조
- `api/` : 두 사람이 만나는 공통 인터페이스 (Combatant 등). 합의 후에만 수정
- `game/` : 전투 엔진, 입출력, 스테이지 진행
- `characters/` : 캐릭터 구현
- `docs/` : 설계문서(`design.md`), SRS(`srs.md`), 변경기록(`CHANGELOG.md`), 다이어그램

## 컴파일
```
javac -encoding UTF-8 -d out api/*.java game/*.java characters/*.java
```

## 작업 규칙
- 작은 단위로 자주 커밋합니다. 메시지는 `feat:`, `fix:`, `docs:`로 시작합니다.
- 코드나 규칙이 바뀌면 `docs/design.md`와 `docs/CHANGELOG.md`도 같이 갱신합니다.
- `api/` 수정은 상대와 합의한 뒤에 합니다.
- 각자 자기 폴더를 담당하고, 다른 사람 폴더를 고칠 때는 미리 알립니다.
