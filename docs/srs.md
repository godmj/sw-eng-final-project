# SRS 초안 (v0.1, 2026-11-25)

> 초안입니다. 전투 규칙과 캐릭터 수치는 `docs/rules.md`에 정리했고, 테스트하며 조정합니다. 작업명세서 제출 마감은 11/30이며, 제출 후에도 계속 갱신합니다.

## 1. 개요
- 목적: Java 콘솔 턴제 RPG. 플레이어 파티가 3개 스테이지의 적을 차례로 쓰러뜨리고 마지막에 왕(드래곤)을 처치하면 클리어.
- 범위: 네트워크 없음, 콘솔 입출력, 한 프로그램(두 사람의 코드를 합침).
- 액터: 플레이어(사람), 적 AI(시스템).

## 3. 기능 요구사항
| ID | 요구사항 | 관련 UC |
|---|---|---|
| FR-01 | 게임은 스테이지 3개를 순서대로 진행하고 마지막 적은 왕이다 | UC-10 |
| FR-02 | 턴 순서는 priority 내림차순, speed 내림차순, 파티 순서로 정하고 전투 시작 때 한 번만 정렬한다 | UC-05 |
| FR-03 | 플레이어는 매 턴 공격 / 방어 / 스킬 중 하나를 고른다 | UC-02 |
| FR-04 | 잘못된 입력은 다시 묻고, 스킬 메뉴에서 뒤로 갈 수 있다 | UC-02, UC-03 |
| FR-05 | 방어는 다음 자기 턴 시작에 해제된다 | UC-02 |
| FR-06 | 상태이상은 같은 이름이 걸리면 중첩하지 않고 지속시간만 갱신한다 | UC-08 |
| FR-07 | 독·화상은 방어를 무시하는 피해를 준다 | UC-08 |
| FR-08 | 라운드 상한에 도달하면 양 팀 HP 합 비율로 승패를 정하고 같으면 무승부 | UC-09 |
| FR-09 | 파티 HP는 스테이지 사이에 유지된다 | UC-10 |
| FR-10 | 캐릭터는 화면에 출력하지 않고 결과 값(ActionResult)만 돌려준다 | UC-06, UC-07 |
| FR-11 | 파티는 전사·궁수·사제 3인으로 구성한다 | UC-01 |
| FR-12 | 명중은 기본 90%에 보정값을 더하고, 치명타는 피해 2배이며 확률은 직업별이다(전사 10%, 궁수 20%, 사제 5%, 적 5%) | UC-06 |
| FR-13 | 피해 계산 순서는 무기막기 → 방어 버프 → 방어 행동 → 갑옷 → 최소 1이다 | UC-06 |
| FR-14 | 스킬은 MP 없이 쿨다운만 사용하고, 자기 턴 시작에 쿨다운이 1 감소한다 | UC-07 |
| FR-15 | 스킬 목록: 전사(강타, 무기막기), 궁수(독화살, 연사, 조준사격), 사제(힐, 공격 버프, 방어 버프), 고블린(모래 뿌리기), 드래곤(화염 숨결) | UC-07 |
| FR-16 | 상태이상은 화상(턴당 5, 3턴), 독(턴당 3, 4턴), 실명(명중 -30%, 2턴)이다. 버프와 무기막기는 캐릭터가 보관한다 | UC-08 |
| FR-17 | 스테이지 사이에 아군 HP는 회복하지 않는다 | UC-10 |
| FR-18 | 적은 방어하지 않고 기본 공격과 스킬만 사용한다 | UC-04 |

## 4. 비기능 요구사항
- 난수는 게임이 만든 Random 하나만 사용해 시드 고정으로 재현할 수 있다.
- 입력이 끝나도(파이프 입력 등) 프로그램이 멈추지 않는다(자동 방어).
- 공통 인터페이스(api/)는 두 사람이 합의한 뒤에만 수정한다.

## 7. 제안서 대비 변경 사항
- 드래곤의 상태이상은 화상으로 한다.
- 7단계 구성이던 마법사·고블린을 궁수·사제로 바꾼다. (고블린은 1·2스테이지 적으로 사용)
- 어지러움 상태이상은 제외한다(속도 변경 효과 금지 규칙과 충돌).
- MP는 제외하고 쿨다운만 사용한다.
- 파티는 전사 1명 필수에서 전사·궁수·사제 3인으로 확정했다(시뮬레이션에서 1인은 드래곤을 이길 수 없음).
